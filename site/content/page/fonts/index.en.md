This site is typeset with three open-source fonts: **Zhuque Fangsong** for Chinese body
text and quotes, **Literata** for Latin body text, and **EB Garamond** for Latin
headings. Interface and navigation text uses the platform's own sans-serif; no extra
font file is loaded for it.

All three are self-hosted as WOFF2 under `static/fonts/` and licensed under the
SIL Open Font License 1.1, which allows use, modification and redistribution, including
commercially.
